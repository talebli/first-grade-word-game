# 🎒 بازی کلمه‌سازی کلاس اولی‌ها (کلمه‌ساز هوشمند اول دبستان)

یک وب‌اپلیکیشن شاد، آموزشی و تعاملی برای دانش‌آموزان پایه اول دبستان که یادگیری نشانه‌های الفبای فارسی را به یک بازی هیجان‌انگیز تبدیل می‌کند.

## 🌟 ویژگی‌های کلیدی

### ۱. انتخاب بر اساس سرفصل رسمی کتاب فارسی اول دبستان
- **پیش‌تنظیم‌های سریع درس‌ها:** امکان انتخاب نشانه‌ها با یک کلیک (مثلاً «تا درس ۱: آ، ب»، «تا درس ۳: م، س»، «تا درس ۶: ن، ای»، «کل نشانه‌های ۱» و «نشانه‌های ۲»).
- **انتخاب دستی و انعطاف‌پذیر:** والدین و معلمان می‌توانند دقیقاً مشخص کنند کدام نشانه‌ها و صداها به دانش‌آموز تدریس شده است.
- **تضمین پداگوژیک:** بازی **فقط و فقط کلماتی را پیشنهاد می‌دهد** که تمام حروف و نشانه‌های آن توسط کودک آموخته شده باشد.

### ۲. بخش‌بندی و صداکشی کلمات (منطبق بر متد تدریس اول دبستان)
برای هر کلمه، بخش‌ها و صداکشی دقیق نمایش داده می‌شود:
- کلمه: **باران**
- بخش‌ها: `[با] - [ران]` (۲ بخش)
- صداها: `بـ / ا / ر / ا / نـ` (۵ صدا)

### ۳. چهار حالت بازی جذاب و آموزنده
1. **جورچین کلمه (کلمه‌ساز اصلی):** حروف کلمه به صورت کارت‌های به‌هم‌ریخته نمایش داده می‌شوند و کودک آن‌ها را در خانه‌های خالی می‌چیند.
2. **نشانه گم‌شده (جای خالی):** یک حرف از کلمه خالی است و کودک از بین گزینه‌ها نشانه درست را انتخاب می‌کند.
3. **کارگاه کلمه‌سازی آزاد (سفره الفبا):** کودک می‌تواند با نشانه‌های آموخته‌شده، هر کلمه‌ای را بسازد و با زدن دکمه «بررسی کلمه»، در صورت معنی‌دار بودن جایزه بگیرد!
4. **دفترچه افتخارات:** تمام کلماتی که دانش‌آموز کشف کرده و ساخته است در یک دفترچه با ستاره‌ها، اموجی‌ها و امکان شنیدن تلفظ صوتی ذخیره می‌شود.

### ۴. جلوه‌های بصری و صوتی کودکانه
- سیستم صوتی سنتز شده با Web Audio API (بدون نیاز به فایل خارجی و ۱۰۰٪ آفلاین).
- تلفظ صوتی هوشمند کلمات با موتور SpeechSynthesis.
- انیمیشن پرتاب کاغذ رنگی و ستاره (Confetti).
- طراحی بزرگ، رنگارنگ و دکمه‌های با بازخورد ۳ بعدی، مناسب برای تبلت و صفحه‌لمسی.
